02 / 05

5 Layers, One
Unified Directory

Every concern (AI rules, diff-based risk selection, fixtures, and accessibility suites) has an explicit boundary:

.cursor/rules/          # AI QA guardrails (a11y + POMs)
scripts/risk-engine.ts  # git diff -> targeted tag runner
src/fixtures/           # AxeBuilder + keyboard focus helpers
tests/auth.setup.ts     # <50ms API session state caching
tests/
  ├── a11y/             # Static WCAG 2.1 AA DOM scans
  ├── keyboard/         # Tab order & modal focus traps
  └── screen-reader/    # Guidepup VoiceOver audio checks

CI SPEED & TARGETING
03 / 05

Keep CI Under 3 Minutes
With a Diff Risk Engine

Running every screen-reader and accessibility suite on documentation edits wastes CI minutes and developer patience.

🧠

Changed-File Risk Selection

scripts/risk-engine.ts inspects git diff on every PR and automatically selects @a11y and @keyboard suites only when UI components change.

⚡

Sharded Parallel Execution

GitHub Actions shards specs across runners so full PR validation completes in under 3 minutes.

ELIMINATING LOGIN OVERHEAD
04 / 05

Sub-50ms API Auth
Via storageState

Legacy E2E suites spend up to 40% of their runtime typing credentials into login forms before every spec.

🔑

Authenticate Once, Reuse Everywhere

An isolated auth.setup.ts fetches a session token via direct API call once and persists storageState to disk.

🚀

Zero UI Login Flakiness

Every E2E, keyboard, and WCAG spec launches already authenticated in under 50 milliseconds.
