THE SYSTEMS INVARIANT
04 / 07
NEVER STOP THE LINE

3-Phase Dual-Run
Migration Architecture

Run old and new suites side by side per domain, and cut over only after proving speed and parity.

1️⃣

Phase 1: Dual-Run in GitHub Actions

Legacy suite stays the required merge gate while migrated Playwright specs run in parallel as informational checks.

2️⃣

Phase 2: Parity & Speed Verification

Verify each migrated domain runs in under 1/3rd the legacy time with zero false positives.

3️⃣

Phase 3: Domain-by-Domain Cutover

Delete legacy specs per module and promote Playwright to the required PR check—zero release freeze.

ARCHITECTURE UPGRADE
05 / 07

Accessible POMs &
Sub-50ms Auth Seeding

Replace brittle XPaths and slow UI logins with Accessibility Tree locators and cached API sessions.

❌ Legacy: XPath + UI Login on Every Test 
// 40% of runtime spent logging in via UI
await page.locator('//div[@class="btn-save"]').click();
✅ Playwright: Role Locators + storageState 
// auth.setup.ts caches JWT once -> <50ms per test
this.submitButton = page.getByRole('button', { name: /save changes/i });
this.searchField  = page.getByLabel(/search courses/i);
