THE ROOT CAUSE
02 / 05

Why LLMs Default to
2018 Selenium Habits

Public training data is full of legacy scripts. Without guardrails, AI assistants reproduce three classic anti-patterns:

🎯

1. Brittle CSS & XPath Chains

Deep DOM paths (div.container > div:nth-child(2)) break the moment a designer adjusts Tailwind classes.

⏱️

2. Arbitrary waitForTimeout() Sleeps

Hardcoded 5-second waits inflate CI runtime and still flake whenever backend latency spikes.

🍝

3. Monolithic Test Scripts

200-line procedural specs with zero Page Object encapsulation become unmaintainable within weeks.

THE CURSOR CONTRACT
03 / 05

The Accessibility-First
Locator Hierarchy

Force the AI to query the browser's Accessibility Tree in this exact priority order:

1.page.getByRole('button', { name }) (First choice)
2.page.getByLabel('Work Email') (Form fields)
3.page.getByPlaceholder(...) (When no label exists)
4.page.getByText('Success') (Non-interactive text)
5.page.getByTestId(...) (Last resort only)
