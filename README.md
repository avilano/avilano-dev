# 🌐 avilano.dev — Official Consulting Website

Official productized consulting website for **avilano.dev** — Senior AI QA Enablement, Playwright Test Architecture, and Automated WCAG 2.1 Level AA Accessibility Systems.

Built with **[Astro](https://astro.build/)** + **Tailwind CSS**.

## 🚀 Quick Start
```bash
npm install
npm run dev
```

Visit [http://localhost:4321](http://localhost:4321) to preview locally.

## 📦 Build for Production
```bash
npm run build
```
Deploy instantly to **Cloudflare Pages** or **Vercel** with zero configuration.
